# Historias de usuario

1. Como **organizador**, quiero registrar un jugador para poder incluirlo en un equipo.
2. Como **organizador**, quiero armar equipos con sus integrantes para saber quién juega con quién.
3. Como **organizador**, quiero programar un partido entre dos equipos con su fecha para que todos sepan cuándo juegan.
4. Como **organizador**, quiero registrar el resultado de un partido para que quede guardado y no se pueda cambiar después.
5. Como **organizador**, quiero ver la tabla de posiciones para saber quién va ganando.
